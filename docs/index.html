DeepSeek Harness PR Review

Headless PR review: description verified claim-by-claim against real code, docs checked against reality, requirement impact flagged. View on GitHub

  • Verifies — each PR description claim vs actual code, with file:line evidence
  • Checks — repo docs against real code: Match / Stale / Wrong / Fabricated
  • Flags — requirement impact, risks, and unresolved review threads

Quickstart

pip install -e '.[web]'
gh auth login
export DEEPSEEK_API_KEY=sk-...

python -m src.run owner/repo 123   # review one PR
python -m src.autoreview --daemon  # auto review every 2 min
python -m web.server               # dashboard at http://127.0.0.1:6789
